My Overtime Website — ZIP ফাইল

ব্যবহার:
১. ZIP-এর সব ফাইল একসঙ্গে একই জায়গায় রাখুন; কোনো ফোল্ডারের ভিতরে রাখার দরকার নেই।
২. HTTPS hosting-এ index.html, sw.js, manifest.webmanifest, logo.svg এবং অন্যান্য ফাইল আপলোড করুন।
৩. APK ফাইলও index.html-এর পাশে আপলোড করুন এবং HTML-এর releases তালিকায় একই ফাইলের নাম দিন।
৪. releases তালিকায় নতুন তারিখ যোগ করলে ওয়েবসাইট তারিখ অনুযায়ী সাজাবে। সবচেয়ে নতুন তারিখে Latest এবং বাকি তারিখগুলোতে Old দেখাবে।
৫. শুধু APK ফাইল আপলোড করলেই সাধারণ static website নিজে থেকে সেটি খুঁজে পায় না—নতুন ভার্সন যোগ করতে index.html-এর releases তালিকায় এক লাইন যোগ করতে হবে।
৬. প্রথমবার ওয়েবসাইট চালু করতে ইন্টারনেট প্রয়োজন। Service Worker ক্যাশ হওয়ার পর ওয়েবসাইটের মূল অংশ অফলাইনে খুলতে পারে। Firebase-এর লাইভ তথ্য ও APK ডাউনলোডের জন্য ইন্টারনেট প্রয়োজন।
